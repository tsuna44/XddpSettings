# docs/adr — XddpSettings 設計判断記録

このディレクトリは **XddpSettings リポジトリ自身**（XDDP ツールのスキル・エージェント定義）の
設計判断を記録する。**開発リポジトリ限定の参考資料であり、`setup.sh` によるデプロイ対象
（`~/.claude/`）には含まれない。** スキル・エージェント本文からの参照は実行時に読む必要がなく、
背景を知りたい開発者向けの手がかりとして機能する。
